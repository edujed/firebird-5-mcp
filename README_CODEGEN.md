# Code Generation Examples

Examples of code generated by `firebird_generate_dev` and `firebird_generate_view_dto`.

## `firebird_generate_dev`

Generates development code from table schemas.

**Arguments:**
- `tables` (required): Array of table names (max 20)
- `language` (required): `java`, `go`, `rust`, `typescript`, `protobuf`, `openapi`, `graphql`, `python`, `json_schema`, `lazarus`, or `svelte`
- `database` (optional): Database name
- `include_fks` (optional): If true, generates named FK relations (Java `@ManyToOne`) or FK comments

### Java (JPA + Lombok)

```json
{
  "tables": ["USERS"],
  "language": "java",
  "database": "shop",
  "include_fks": true
}
```

```java
@Entity
@Table(name = "USERS")
@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
public class User {

    @Id
    @Column(name = "ID")
    private Integer id;

    @ManyToOne
    @JoinColumn(name = "CUSTOMER_ID")
    private Customer customer;

    @Column(name = "EMAIL", length = 250)
    private String email;

    @Column(name = "PASSWORD_HASH", length = 250)
    private String passwordHash;

    @Column(name = "ACTIVE")
    private Boolean active;

    @Column(name = "CREATED_AT")
    private LocalDateTime createdAt;

    @Column(name = "UPDATED_AT")
    private LocalDateTime updatedAt;

    @Column(name = "CREATED_BY")
    private Integer createdBy;

    @Column(name = "UPDATED_BY")
    private Integer updatedBy;

    @Column(name = "DELETED_AT")
    private LocalDateTime deletedAt;
}
```

```go
// User maps to table USERS

    Id           sql.NullInt32  `db:"ID" json:"id"`
    CustomerId   sql.NullInt32  `db:"CUSTOMER_ID" json:"customerId"` // FK → CUSTOMERS.ID
    Email        sql.NullString `db:"EMAIL" json:"email"`
    PasswordHash sql.NullString `db:"PASSWORD_HASH" json:"passwordHash"`
    Active       bool           `db:"ACTIVE" json:"active"`
    CreatedAt    *time.Time     `db:"CREATED_AT" json:"createdAt"`
    UpdatedAt    *time.Time     `db:"UPDATED_AT" json:"updatedAt"`
    CreatedBy    i32            `db:"CREATED_BY" json:"createdBy"`
    UpdatedBy    i32            `db:"UPDATED_BY" json:"updatedBy"`
    DeletedAt    *time.Time     `db:"DELETED_AT" json:"deletedAt"`
}
```

## `firebird_generate_view_dto`

Generates DTOs/records from views (resolved metadata).

**Arguments:**
- `views` (required): Array of view names (max 20)
- `language` (required): `java`, `go`, `rust`, `typescript`, `protobuf`, `openapi`, `graphql`, `python`, `json_schema`, `lazarus`, or `svelte`
- `database` (optional): Database name

Generated code is read-only (no entity annotations, no FKs). Supports the same languages as `firebird_generate_dev`.
